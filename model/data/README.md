# Data

Most files here are generated by the pipeline and do not need to be downloaded manually. The one exception is the Retrosheet gamelogs.

## Required: Retrosheet Gamelogs

Download game logs for each season you want to include and place them here:

```
model/data/gl2023.txt
model/data/gl2024.txt
model/data/gl2025.txt
```

Download from: https://www.retrosheet.org/gamelogs/

Each year is a separate zip — extract the `.TXT` file and rename it to `gl{year}.txt`. The column format is documented in [gamelog_col_description.txt](gamelog_col_description.txt).

The pipeline (2023–2024 train, 2025 test) requires all three years. If you only want a subset, adjust the train/test split logic in `scraper.py`.

## Generated Files

These are created automatically by `scraper.py` and the model notebook — do not edit manually:

| File / Folder | Created by | Contents |
|---|---|---|
| `games.csv` | `scraper.py` | Parsed gamelogs with home_win label and player ID columns |
| `player_id_map.csv` | `scraper.py` | Retrosheet → MLBAM ID mapping (1,519 players) |
| `stats_cache/` | `scraper.py` | Per-date batting/pitching stats from pybaseball, disk-cached |
| `train_features.parquet` | `scraper.py` | Feature matrix for 2023–2024 games (4,859 rows, 122 cols) |
| `test_features.parquet` | `scraper.py` | Feature matrix for 2025 games (2,430 rows, 122 cols) |
